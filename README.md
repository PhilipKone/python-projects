# Python Projects & Tutorials Portfolio

A professional collection of educational resources and functional applications, mapping the journey from Python fundamentals to full-stack static web development.

---

## 🚀 Repository Overview

This repository is organized into three distinct segments, designed for both learning and practical demonstration:

### 1. 📚 [Python Tutorials](./tutorials/)
Comprehensive, interactive learning materials for mastering Python.
*   **Core Concepts:** Variables, Data Types, Functions, and Flow Control.
*   **GUI Basics:** Introduction to **Gradio** and **Turtle Graphics**.
*   **Format:** Hosted as a Google Colab compatible Jupyter Notebook.
*   👉 **[Start Learning Now](./tutorials/Python_Tutorials_for_Fiifi.ipynb)**

### 2. 🌐 [Web Applications](./web-apps/)
High-performance, responsive front-end demonstrations.
*   **Project Hero:** **To-Do App (Static)**
*   **Stack:** HTML5, CSS3, Vanilla JavaScript.
*   **Deployment:** Automated via GitHub Actions.
*   🚀 **[Live Demo](https://philipkone.github.io/python-projects/web-apps/todo-static/)**

### 3. 🐍 [Python Applications](./python-apps/)
Pure Python implementations focusing on logic and persistence.
*   **Project Hero:** **Python To-Do CLI**
*   **Stack:** Python 3, JSON Persistence.
*   **Functionality:** Complete CRUD (Create, Read, Update, Delete) cycle via the terminal.
*   🛠️ **[View Implementation](./python-apps/todo-cli/)**

## 📦 Getting Started

### Local Setup
1.  Clone the repository:
    ```bash
    git clone https://github.com/PhilipKone/python-projects.git
    ```
2.  Navigate to your project of choice:
    *   **CLI App:** `cd python-apps/todo-cli && python todo.py`
    *   **Web App:** Open `web-apps/todo-static/index.html` in your browser.
