# Static To-Do Application

A responsive, client-side task manager built with Vanilla JavaScript, HTML, and CSS.

## 🚀 Features
- **Modern UI:** Clean, minimalist design with a responsive layout.
- **Client-Side Logic:** All task management is handled via JavaScript in the browser.
- **Persistence:** Uses browser native features for a seamless user experience.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure.
- **CSS3:** Custom styling and flexbox layouts.
- **JavaScript (ES6):** DOM manipulation and event-driven logic.

## 🌐 Live Deployment
This application is automatically deployed via GitHub Pages at:
**[View Live Application](https://philipkone.github.io/python-projects/web-apps/todo-static/)**

## 📂 Structure
- `index.html`: Entry point and UI structure.
- `style.css`: Visual design and transitions.
- `app.js`: Core application logic and state management.
