# Python To-Do CLI

A simple, persistent command-line task manager built with Python.

## Features
- **Persistent Storage:** Tasks are saved to a `tasks.json` file automatically.
- **Easy Management:** Add, view, and delete tasks directly from your terminal.
- **Clean Logic:** Demonstrates Python basics including File I/O, Error Handling, and Control Flow.

## How to Run
Ensure you have Python 3 installed, then run:

```bash
python todo.py
```

## Structure
- `todo.py`: The main application script.
- `tasks.json`: Automatically generated storage file.
